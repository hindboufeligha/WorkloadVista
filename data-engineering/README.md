# Data Engineering

This module contains the scripts used to inspect, prepare, and validate the workload trace data for WorkloadVista.


## Data Pipeline

The initial pipeline uses the `instance_usage` table from Google Borg Cluster Traces v3 (2019), Trace B.

| Step | Script | Description  |
|---|---|---|
| 1. Profiling| `profile_machines.py` | Counts records per machine and checks CSV structure.   |
| 2. Selection| `select_machines.py` |  Selects distinct machines using uniform random sampling without replacement. |
| 3. Extraction | `extract_sample.py` | Extracts all records belonging to the selected machines |
| 4. Valdation | `validate_sample.py` | Validates the extracted sample's schema, machine IDs and record counts. |


## Data Configuration

The original dataset and generated data files are stored outside the Git repository to avoid committing large data files.

The expected local data workspace:

```text
WorkloadVista-Data/
├── raw/
│   ├── clusterdata_2019_b_instance_usage.csv
├── samples/
└── reports/
```

Obtain the dataset from the [Google Cluster Data repository](https://github.com/google/cluster-data).

By default, the scripts expect `WorkloadVista-Data` to be a sibling directory of the cloned `WorkloadVista` repository. Its location can be overriden using the `--data-dir` argument.

## Running the Pipeline

From the repository root, execute the scripts in the following order: 

```text
python .\data-engineering\scripts\profile_machines.py
python .\data-engineering\scripts\select_machines.py
python .\data-engineering\scripts\extract_sample.py
python .\data-engineering\scripts\validate_sample.py
```

Each step depends on outputs generated by the preceding step.


## Config Options

The scripts support command-line arguments:

| Argument | Applicable script(s) | Default  |
|---|---|---|
| `--data-dir`| All scripts | Sibling `WorkloadVista-Data` directory  |
| `--sample-size` | `select_machines.py` | `5` |
| `--seed` | `select_machines.py` | `42` |

Use `--help` to display the available arguments for each script.

For example, to use a different data directory:

```powershell
python .\data-engineering\scripts\profile_machines.py --data-dir "D:\Data\WorkloadVista-Data"
```

## Current Development Sample

- **Trace**: Google Borg Cluster Traces v3 (2019), Trace B.
- **Table**: `instance_usage`.
- **Selected machines**: 5
- **Sampling method**: Uniform random sampling without replacement
- **Random seed**: 42
- **Extracted records**: 2457

The selected sample is intended for initial development and testing. It is not statistically representative of the full cluster workload dataset.
